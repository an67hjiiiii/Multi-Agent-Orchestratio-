# S0 End-to-End Spike

## Goal
See the final product shape early without claiming research completion.

## Done when
- New clean backend boots.
- Text source import works.
- A, B, C, C-P, C-N, C-O all run through one codebase.
- Inspector shows tasks, selected/dropped evidence, flags, metrics and raw trace.
- FakeProvider passes tests.
- Ollama provider can be enabled without changing research code.
- 3–5 development requests can be manually compared.

## Not S0 scope
- Dense embeddings/vector DB.
- Full semantic normalizer.
- Full overlap-aware allocation formula.
- 120-case benchmark.
- HERA/Experience/QLoRA.
- Advanced UI polish.
