# Project-local Codex skills

This directory contains skills deliberately exposed for this repository.
`local-mrag-governance` is project-authored; other directories are minimal,
commit-pinned copies of upstream skills documented in
`reports/codex_skill_stack/provenance.md` and `skill-manifest.json`.

Do not add global PATH changes, duplicate copies, or unrelated agent frameworks
here. Conditional skills remain uninstalled until their documented trigger.
