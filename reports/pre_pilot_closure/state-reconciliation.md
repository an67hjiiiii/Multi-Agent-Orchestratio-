# Canonical-state reconciliation

`.project/project-state.yaml` remains the only canonical state file and was not
promoted. Direct evidence verifies reachable local Ollama `0.33.3`, `qwen3:4b`
availability, and small local A/B/C acceptance runs.

It does **not** freeze a research model digest, hardware identity, benchmark
corpus/version, approved full-pilot set, gold obligations/evidence, or the full
metric-recording contract. Therefore changing empirical validation to PASS or
marking M1 empirically complete would be unsupported.

`M1_PILOT_AUTHORIZED` is preserved. `M2: PLANNED` is not authorization and no
M2 readiness or state transition is claimed.
